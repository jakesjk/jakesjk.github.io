원칙 01 · 검증 · 해결 사례 B · Lunarc

자동 검증을 모두 통과한 PR 11건을 다른 모델로 다시 읽어 놓친 결함 2건을 찾아 고쳤습니다

문제

  1. 빌드 · 테스트 · 심볼 대조를 모두 통과한 PR 11건이 있었습니다.
  2. 같은 모델은 같은 맹점을 반복하므로 세 겹을 통과해도 결함이 남는다고 봤습니다.
  3. 작성과 다른 모델이 처음부터 다시 읽는 라운드를 두었습니다.

해결 과정

  1. 의심 가는 곳을 모두 적되 코드로 반증된 의심은 무죄로 근거와 함께 기록했습니다.
  2. 닉네임 변경 API가 길이만 검사해 욕설 · 태그가 공개 화면에 나갈 수 있던 공백을 찾아 필터와 테스트를 붙였습니다(#440).
  3. 캘린더 연동 두 개를 함께 켜면 같은 일정이 두 번 그려지는 문제를 데이터 층에서 외부 소스를 걸러 고쳤습니다(#441).
  4. 고칠 가치가 낮은 한계 1건은 고치지 않고 승격 조건과 함께 적어 두었습니다.

결과

  • 2찾아서 고친 신규 결함
  • 11다시 읽은 PR
  • 4무죄로 기록한 의심
  • 1적어 둔 한계
