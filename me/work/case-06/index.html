확인 시트가 사라져도 9/9 통과하던 배선 테스트를 고쳐 화면 결함을 잡게 했습니다

문제

  1. 빌드와 테스트가 모두 통과하는데 화면 동작이 달라지는 일이 반복됐습니다.
  2. 그래서 어떤 뷰가 어떤 함수를 부르는지 그 배선을 잠그는 테스트를 붙였습니다.
  3. 코드를 일부러 망가뜨려 보니 이 테스트가 두 번 거짓으로 통과했습니다.

해결 과정

  1. 호출부를 // 로 주석 처리해도 문자열이 소스에 남아 통과했고 /* */ 로 감싸 확인 시트가 사라졌는데도 9건이 모두 통과했습니다.
  2. 주석이 아닌 줄에 있는 호출만 배선으로 인정하도록 공용 검사를 고쳤습니다.
  3. 블록 끝을 표시 문자열 대신 중괄호 짝으로 찾게 바꿔 검사 범위가 조용히 커지는 길을 없앴습니다.
  4. 주요 변경마다 코드를 망가뜨려 테스트가 실제로 실패하는지 확인하고 그 결과를 커밋에 남깁니다.

결과

  • 9/9확인 시트가 사라졌는데도 통과하던 배선 잠금
  • 2종막은 오판 경로
  • 1,900+상시 통과하는 iOS · 백엔드 테스트
  • 50건변이 결과를 남긴 PR
