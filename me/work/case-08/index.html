같은 거절에 추론을 두 번씩 쓰던 재시도를 없애 거절 경로 추론 비용을 절반으로 줄였습니다

문제

  1. 번역 결과가 저장 전 검사에 걸리면 한 번 더 물어보게 짜 두었습니다.
  2. 그런데 모델 설정이 temperature 0이라 같은 입력에는 같은 답이 나와 같은 거절만 반복됐습니다.
  3. 거절 1건에 추론 2회를 쓰고 결과는 없었고 사용자가 누를 때마다 되풀이됐습니다.

해결 과정

  1. 시도 상한을 2에서 1로 내리고 상수는 남겨 온도를 올리는 날 되돌릴 수 있게 했습니다.
  2. 기존 테스트 3건이 이 낭비를 정답으로 고정하고 있었고 그중 하나는 실제로는 일어날 수 없는 응답을 흉내 내고 있었습니다.
  3. 상한이 1이 되자 분기를 구분하지 못하는 테스트가 생겨 테스트에서만 상한을 올릴 수 있게 해 세 분기를 각각 확인했습니다.

결과

  • ½거절 경로의 추론 호출
  • 2 → 1시도 상한
  • 3건낭비를 고정하던 테스트 정리
  • 5종실패를 확인한 변이
