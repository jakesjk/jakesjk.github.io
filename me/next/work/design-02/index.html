개요

주간 회고

설계서에는 주간 회고를 봉인한다고 돼 있었고 저도 승인했습니다. 저장하면 수정할 수 없게 해서 그 시점의 진심을 고정하는 의식 장치였습니다. 만들어 놓고 써 보니 다르게 읽혔습니다. 다시 여는 진입이 약해서 "봉인"보다 "다시 볼 수 없다"로 느껴졌습니다. 의식이 상실이 됐습니다.

01

결정

승인했던 결정을 번복했습니다. 봉인을 버리고 저장 → 다시 열람 → 수정, 일간 회고와 같은 관용으로. 흐름도 다시 짰습니다.
장면을 다섯으로. 좋았던 것 · 아쉬웠던 것 · 시도해보고 싶었던 것 · 개선해 볼 것 · 다음 주의 나에게 쓰는 편지
흐름을 끊던 "계획된 일정 확인" 장면과 "이 주의 기록" 타일은 삭제
한 줄 입력칸을 여러 줄로. 한 줄은 회고를 쓰기엔 너무 좁았습니다
문안 규율. "좋았던 것" 단독 금지, 전부 "이번 한 주의 ○○" 형태로
같은 날 실제 사고도 잡았습니다. 리추얼 요일을 화요일로 옮겼는데 카드가 지난 캘린더 주를 가리켰습니다. 주 경계가 일~토 고정이었기 때문입니다. 회고 주 = 리추얼 요일 기준 앞 7일로 바꿔 요일과 주가 분리되지 않게 했습니다.

기록

잰 숫자와 출처

  • 측정 · 흐름 재설계

    5장면좋았던 것부터 다음 주의 나에게 쓰는 편지까지

  • 측정 · 결과

    4슬롯 + 편지저장 뒤 다시 열어 고칠 수 있는 입력 구조

  • 측정 · 사고 수정

    앞 7일리추얼 요일 기준으로 회고 주를 다시 정의

  • 결과

    5장면 4슬롯 + 편지 · 저장 후 수정 가능 · 구버전 저장분(자유문·KPT) 판독은 유지

  • 배운 것

    설계서에 이유가 있어도 사용자에게 그 이유가 전달되지 않으면 의식은 상실로 읽힙니다. 승인한 결정을 번복하는 비용보다, 다시 못 보는 회고를 남기는 비용이 컸습니다. 번복은 설계서까지 같이 고쳐야 번복입니다.
